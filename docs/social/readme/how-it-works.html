Nuvora · How it worksOne request, end to end

A question goes in. An answer with receipts comes out.

01 · ROUTE

Pick a model you trust

Requests go only to model endpoints on your allow-list: OpenAI-compatible (vLLM too), Ollama, AWS, or the offline demo.

02 · GROUND

Retrieve the evidence

Hybrid BM25 + vector search over your workspace’s knowledge bases, scoped per tenant.

03 · GUARD

Check in and out

Guardrails redact secrets and block policy hits before the model sees them, and again before you do.

04 · RECORD

Write the evidence

Citations, tokens, cost, and a hash-chained audit event, so anyone can verify what happened later.
